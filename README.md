# SmartDay Desktop 2.0 — دستیار مدیریت شخصی

نسخه دسکتاپ مستقل برای Windows 10 و Windows 11 با اولویت آفلاین. داده‌ها در پوشه اختصاصی کاربر ذخیره می‌شوند و مدیریت وظایف، پروژه‌ها، یادآورها، دفترچه مخاطبین، ایده‌ها، حسابداری، خلق‌وخو و سایر بخش‌های محلی بدون اینترنت کار می‌کنند. درخواست استخراج متادیتای یک وب‌سایت، استفاده از AI و همگام‌سازی با نسخه آنلاین ذاتاً به اینترنت نیاز دارند؛ اطلاعاتی که قبلاً دریافت و ذخیره شده‌اند، آفلاین نیز در دسترس می‌مانند.

## امکانات این نسخه

- پروژه‌ها با فضای اختصاصی برای امور/پیگیری‌ها، وظایف اجرایی و یادداشت‌ها
- وظایف با وضعیت، اهمیت، فوریت، مهلت شمسی، پروژه مرتبط و زمان تخمینی
- سه روش بهره‌وری: Kanban، Must / Should / Want و ماتریس آیزنهاور، همراه با راهنمای کامل
- یادآورهای جداگانه شخصی و کاری، تکرار روزانه/هفتگی/ماهانه و اعلان Native ویندوز
- بانک ایده با مراحل ثبت اولیه، بررسی و آماده اقدام؛ امکان مرتب‌سازی با AI
- نگهداری وب‌سایت‌ها با استخراج خودکار عنوان، meta description و Open Graph از URL و دسته‌بندی AI
- دفترچه مخاطبین با تلفن، ایمیل، سازمان و فوریت پیگیری
- یادداشت‌های عمومی و متصل به پروژه
- اهداف با مقدار فعلی/هدف یا محاسبه درصد پیشرفت از پروژه مرتبط؛ تحلیل AI
- حسابداری شخصی: حساب‌ها، درآمد، هزینه، دسته‌بندی و مانده محاسبه‌شده
- Habit Tracker سبک (اولویت پایین) و ثبت روزانه Mood Tracker
- تقویم شمسی و ورود تاریخ شمسی در فرم‌های جدید
- پوسته روشن/تیره/هماهنگ با ویندوز، با امکان تغییر دستی
- System Tray؛ بستن پنجره برنامه را پنهان می‌کند و فرایند و اعلان‌ها ادامه دارند
- ویجت شناور دسکتاپ همیشه‌رو (نمای کارهای نزدیک و ثبت سریع)
- پشتیبان‌گیری و بازیابی JSON
- اتصال به BoxAPI با نگهداری رمزنگاری‌شده کلید در سیستم‌عامل
- زیرساخت همگام‌سازی آنلاین با ادغام رکوردها بر اساس شناسه و آخرین زمان ویرایش

## نکته مهم درباره ویندوز

این پوشه یک **پروژه دسکتاپ آماده ساخت** است. فایل EXE در این محیط ساخته نشده است؛ برای تولید Installer ویندوز باید فرمان ساخت را روی Windows اجرا کنید. پروژه از Electron استفاده می‌کند و برای اجرا یا ساخت به Node.js 24 یا جدیدتر و npm نیاز دارد. Electron 45.5.0 و electron-builder 26.18.0 به‌عنوان نسخه‌های وابستگی تثبیت شده‌اند. نیازی به XAMPP، WAMP یا نصب PHP نیست. برای ساخت روی ویندوز، اینترنت در مرحله دریافت وابستگی‌های npm و بسته‌های Electron لازم است؛ اجرای روزمره برنامه برای ماژول‌های محلی به اینترنت وابسته نیست.

## اجرای توسعه روی ویندوز

1. Node.js نسخه LTS را نصب کنید.
2. پوشه پروژه را استخراج کنید.
3. در PowerShell داخل پوشه پروژه اجرا کنید:

```powershell
npm install
npm start
```

## ساخت فایل نصب ویندوز

برای ساخت Installer و نسخه Portable:

```powershell
npm run dist:win
```

خروجی در پوشه `dist` قرار می‌گیرد:

- `SmartDay-Setup-2.0.0.exe` — نصب‌کننده NSIS با امکان انتخاب محل نصب و ایجاد میانبر
- `SmartDay-Portable-2.0.0.exe` — نسخه قابل حمل

برای ساخت فقط Installer:

```powershell
npm run dist:win:nsis
```

اطلاعات کاربر در `%APPDATA%\SmartDay` ذخیره می‌شود و با حذف برنامه پاک نمی‌شود.

## تنظیم BoxAPI

1. برنامه را اجرا و وارد بخش «تنظیمات» شوید.
2. آدرس پایه را روی مقدار زیر قرار دهید:

```text
https://ai.boxapi.ir/ai/v1
```

3. کلید API را وارد و «دریافت مدل‌ها» را انتخاب کنید.
4. مدل مورد نظر را انتخاب و تنظیمات را ذخیره کنید.

ارتباط از فرایند اصلی Electron انجام می‌شود و کلید در صورت پشتیبانی سیستم‌عامل با `safeStorage` رمزنگاری می‌شود. داده‌های محلی و ابزارهای برنامه برای کارکرد خود به مدل یا اینترنت وابسته نیستند.

## System Tray و یادآورها

- بستن پنجره اصلی همیشه به‌جای خروج، برنامه را به System Tray می‌فرستد. برای خروج کامل از منوی آیکون Tray گزینه «خروج کامل» را انتخاب کنید.
- از منوی Tray می‌توان پنجره اصلی یا ویجت شناور را باز کرد، وظیفه سریع ساخت یا برنامه را کامل بست.
- اعلان‌ها در حالی که SmartDay در Tray فعال است ادامه پیدا می‌کنند.
- اگر کاربر از منوی Tray «خروج کامل» را انتخاب کند یا فرایند برنامه را از Task Manager متوقف کند، اعلان‌ها تا اجرای دوباره برنامه ارسال نمی‌شوند. یادآورهای سررسیدشده بعد از اجرای مجدد قابل مشاهده خواهند بود.

## همگام‌سازی با نسخه آنلاین

همگام‌سازی به endpoint سمت سرور نیاز دارد. فایل همراه پروژه در `online-sync/sync.php` قرار دارد.

1. نسخه SmartDay PHP آنلاین را به‌روزرسانی و فایل `sync.php` را در ریشه همان نصب قرار دهید؛ فایل باید در کنار پوشه `app/` و فایل `api.php` باشد.
2. روی هاست متغیر محیطی `SMARTDAY_SYNC_TOKEN` با حداقل ۳۲ نویسه تصادفی تنظیم کنید. نمونه تولید توکن در PHP:

```php
<?php echo bin2hex(random_bytes(32));
```

3. مطمئن شوید endpoint فقط از طریق HTTPS در دسترس است و پوشه `storage/` همچنان با `.htaccess` محافظت می‌شود.
4. در دسکتاپ به تنظیمات > همگام‌سازی بروید؛ آدرس کامل `https://your-domain/smartday/sync.php` و همان توکن را وارد و همگام‌سازی را فعال کنید.
5. کلاینت ابتدا داده سرور را می‌خواند، رکوردها را با نسخه محلی ادغام می‌کند و نتیجه ادغام‌شده را ارسال می‌کند. تعارض‌ها با آخرین `updated_at` حل می‌شوند.

**محدودیت نسخه آنلاین قبلی:** endpoint می‌تواند مجموعه‌داده‌های جدید را در فایل ذخیره‌سازی نسخه PHP حفظ کند، اما رابط نسخه وب 1.0 هنوز صفحات بانک ایده، وب‌سایت‌ها، مخاطبین، اهداف، حسابداری و خلق‌وخو را نمایش نمی‌دهد. برای مشاهده و ویرایش کامل این داده‌ها در مرورگر، رابط آنلاین نیز باید به نسخه 2.x ارتقا یابد. فایل sync به‌تنهایی رابط وب را ارتقا نمی‌دهد.

## ساختار داده و پشتیبان

- اطلاعات اصلی: `%APPDATA%\SmartDay\smartday-data.json`
- کلیدها: `%APPDATA%\SmartDay\smartday-secrets.dat` (رمزنگاری‌شده با قابلیت سیستم‌عامل)
- پشتیبان‌گیری و بازیابی از داخل تنظیمات انجام می‌شود.
- حذف موارد به‌صورت بایگانی نرم انجام می‌شود تا tombstone حذف در همگام‌سازی باقی بماند.

## امنیت و حریم خصوصی

- Renderer به Node.js و فایل‌سیستم دسترسی مستقیم ندارد؛ ارتباط از طریق API محدود Preload و IPC است.
- کلید AI و توکن همگام‌سازی وارد فایل پشتیبان نمی‌شوند.
- scraping وب‌سایت فقط برای URLهای عمومی HTTP/HTTPS طراحی شده است.
- داده‌های شخصی، مخاطبین و اطلاعات مالی در همین کامپیوتر ذخیره می‌شوند؛ در صورت فعال‌سازی همگام‌سازی به سرور انتخاب‌شده کاربر منتقل خواهند شد.
- برای جلوگیری از از دست رفتن داده، پشتیبان دوره‌ای تهیه کنید.

## موارد خارج از دامنه این نسخه

- ویجت فعلی یک پنجره شناور دسکتاپ همیشه‌رو است، نه Windows 11 Widgets Board extension.
- همگام‌سازی فعلاً با دکمه «همگام‌سازی اکنون» اجرا می‌شود؛ اجرای خودکار دوره‌ای در نسخه بعدی قابل افزودن است.
- AI در صورت عدم اتصال اینترنت در دسترس نیست؛ تمام ماژول‌های محلی مستقل از آن فعال هستند.
